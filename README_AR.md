# Point-of-Care Research Platform — Advanced V2

برنامج بحثي مستقل لتوضيح معالجة إشارات IMU وPPG، وتقدير جودة الإشارات، والدمج التكيفي، والمقارنة بطريقة متساوية الأوزان، وإدخال القياسات المخبرية يدويًا.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

يمكن رفع ملفات هذا المجلد إلى GitHub ونشره على Streamlit Community Cloud، مع تعيين `app.py` ملف التشغيل.

## الإدخال

- CSV للإشارات الزمنية بالأعمدة: `time_s, imu_x, imu_y, imu_z, ppg`.
- إدخال يدوي لقياسات EIS وECG وPPG وIMU وغيرها مع الوحدات والتعليقات.
- تجربة بيانات اصطناعية قابلة لإعادة التوليد باستخدام seed.

## النتائج

- تحليل مقاطع زمنية، وجودة كل مستشعر، ودرجة جودة الدمج.
- مقارنة جودة الدمج التكيفي بمتوسط جودة المستشعرات.
- تقدير فاصل bootstrap استكشافي (غير سريري).
- تصدير CSV وJSON.

## الحدود العلمية

هذا ليس جهازًا طبيًا أو خوارزمية تشخيص مرض باركنسون. لا تثبت جودة الإشارة دقة اكتشاف الأمراض. لا ترفع بيانات مرضى معرفة الهوية إلى نشر عام. البيانات المدخلة يدويًا لا تُحفظ بعد إغلاق الجلسة.

## قسم المقترحات البحثية للمؤشرات الحيوية

تحت عنوان **Biomarker concept** يمكن اختيار مجال بحثي ومؤشر حيوي مقترح وإدخال نتائج اختبار المستشعر: حد الكشف المعلن، التركيز المستهدف، تشتت العينة الضابطة، ميل المعايرة، عدد المكررات، CV، الاسترداد، التداخل وزمن القياس. يعرض البرنامج فحص جدوى هندسيًا وخطة تحقق تجريبي ويضيف النتيجة إلى التقرير.

**تنبيه:** هذه ليست خوارزمية تشخيص أو تنبؤ مرضي. المعايير المبدئية أمثلة بحثية وليست حدودًا سريرية معتمدة. لا توجد بيانات مرضى أو نماذج مرضية مدربة في الحزمة.

العنوان المعروض في الواجهة هو **Point-of-Care Research Platform** دون رقم إصدار.
